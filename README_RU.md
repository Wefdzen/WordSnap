**WordSnap** позволяет навести курсор на любое слово или фразу на экране — в 3D-играх, визуальных новеллах, видеороликах, PDF-документах, манге, браузере или любых программах — и мгновенно получить **распознанный OCR-перевод**, подробную **словарную статью Yomitan** и **контекстный анализ от нейросети** в аккуратном всплывающем окне рядом со словом.

Каждое найденное слово можно сохранить в **личный словарь** вместе со скриншотом игрового момента, контекстом предложения, уровнем CEFR и тегами, либо в один клик отправить в **Anki**.

---

## Основные возможности

### 🔍 Мгновенный перевод по наведению
- **Глобальные горячие клавиши и кнопки мыши**: вызывайте словарь нажатием настраиваемой комбинации (по умолчанию `Alt+Q`, средняя кнопка мыши (СКМ) или боковые клавиши X1 / X2).
- **Встроенный Windows OCR**: быстрое и точное распознавание текста средствами Windows без необходимости ставить сторонние пакеты (также доступен Tesseract).
- **Адаптивное всплывающее окно**: плавно всплывает с пружинящей анимацией, никогда не перекрывает исходное слово и автоматически подстраивается под тёмный/светлый фон экрана.

### 🎮 Для игр: Режим «Заморозка экрана»
*Играете в шутер, RPG от 3-го лица или с геймпада, где курсор мыши скрыт или привязан к повороту камеры?*
- **Режим «Заморозка экрана» (Freeze Screen)**: при нажатии горячей клавиши экран мгновенно фиксируется пиксель-в-пиксель, а захват мыши игрой разблокируется (`ClipCursor` / `ShowCursor`).
- **Интерактивная подсветка слов**: все распознанные слова на застывшем кадре подсвечиваются неоновой рамкой при наведении курсора. Просто кликните по любому слову — и откроется карточка перевода!
- **Авто-пауза игр**: автоматически ставит процесс игры на паузу (`NtSuspendProcess`), чтобы вы не пропустили реплики в кат-сценах.
- **Быстрый выход**: нажмите `Esc`, `Alt+Q` или кнопку `✕` в верхней плашке, чтобы мгновенно разморозить экран и продолжить игру.

### 📚 Поддержка офлайн-словарей Yomitan (.zip)
- **100% работа без интернета**: устанавливайте любые словари формата Yomitan / Yomichan в архивах `.zip` (например, `wty-en-ru.zip`, японские JMdict, толковые словари английского).
- **Морфологический поиск (Деинфлексия)**: распознаёт базовые формы слов (например, при клике на `greater` корректно находит `great`, понимает прошедшие времена глаголов и множественное число).
- **Форматирование карточек Yomitan**: транскрипции, грамматические пометки, теги частотности и удобная структура статей.

### 🤖 Двойной ИИ-перевод (Groq и Google Gemini)
- **Контекстный перевод предложений**: нейросеть переводит всё предложение с учётом лора и сленга игры, подсвечивая целевое слово.
- **ИИ-словарь Looktionary**: словарная форма, определение на выбранном языке, уровень языка по шкале CEFR (A1–C2), части речи и синонимы.
- **Сверхбыстрый отклик и надёжность**: поддержка бесплатного **Groq** (скорость ответа <1 секунды) и **Google Gemini** (Gemini 2.5 Flash / 2.0 Flash) с автоматическим переключением моделей при сбоях.

### 🗃️ Интеграция с Anki в 1 клик
- **Синхронизация через AnkiConnect**: прямое подключение к открытому приложению Anki (порт 8765) без необходимости импортировать текстовые файлы.
- **Интерактивный мастер колод**: выберите целевую колоду, тип записи и настройте маппинг полей (`Слово`, `Перевод`, `Контекст`, `Скриншот`, `Аудио`, `Определение`).
- **Быстрое добавление**: зелёный значок `+` в карточке слова моментально создаёт карточку с прикреплённым скриншотом. Если слово уже есть в колоде, приложение уведомит вас об этом.

### 📖 Личный словарь («Слова»)
- **Детальные карточки слов**: список всех сохранённых слов с обрезанными скриншотами игровой сцены, датой, названием игры/окна и тегами.
- **Озвучка (TTS)**: произношение слов вслух.
- **Фильтры и поиск**: фильтрация по языкам, приложениям, уровням CEFR, избранному (★) и пользовательским `#тегам`.
- **Экспорт**: выгрузка базы в форматы CSV, JSON и готовую колоду Anki TSV.

## Горячие клавиши

### Управление на вкладке «Слова»
| Сочетание | Действие |
|---|---|
| `Ctrl+F` | Фокус на поле поиска |
| `Пробел` | Озвучить выбранное слово (TTS) |
| `Delete` | Удалить выбранное слово |
| `Ctrl+D` | Добавить / убрать из избранного (★) |
| `←` / `→` | Предыдущее / следующее слово |

## Установка и скачивание

Готовые сборки для Windows 10/11 доступны во вкладке **[Releases](../../releases)**:

1. **Установщик (`WordSnap-1.0.0-Setup.exe`)**:
   Полноценный мастер установки: выбор папки, создание ярлыка на рабочем столе и в меню Пуск, деинсталлятор.
2. **Портативная версия (`WordSnap-1.0.0-Portable.zip`)**:
   Не требует установки. Распакуйте архив в любое место (на флешку или диск) и запустите `WordSnap.exe`. Все настройки и база данных хранятся внутри папки приложения.

## Запуск из исходного кода

### Требования
- Windows 10 или Windows 11 (для нативного OCR Windows).
- Python 3.11+.

### Установка и запуск
```bash
# Клонируйте репозиторий
git clone https://github.com/Wefdzen/WordSnap.git
cd WordSnap

# Установите зависимости
pip install -r requirements.txt

# Запустите WordSnap
python main.py
```

При первом запуске откроется **Мастер первоначальной настройки**, который поможет выбрать язык интерфейса, тему оформления, горячие клавиши и API-ключ нейросети.

## Настройки

На вкладке **«Настройки»** можно настроить:
- **Внешний вид**: тёмная, светлая или системная тема оформления.
- **Язык интерфейса**: русский или английский.
- **Горячие клавиши**: комбинация на клавиатуре и кнопки мыши (СКМ / боковые кнопки).
- **OCR-движок**: Windows OCR или Tesseract, а также язык текста.
- **Взаимодействие с играми**:
  - *Заморозка экрана* (рекомендуется для шутеров и игр без видимого курсора).
  - *Авто-пауза игр* (приостанавливает процесс игры во время просмотра перевода).
  - *Развернуть игру во весь экран* (растягивает оконные игры).
- **ИИ-источники**: бесплатный API-ключ [Groq](https://console.groq.com/keys) или [Google Gemini](https://aistudio.google.com/app/apikey).
- **Словари и Anki**: установка словарей Yomitan и настройка полей AnkiConnect.
